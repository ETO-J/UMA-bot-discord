## 二、Application Details（应用详情）

### 字段：What does your application do?（你的应用是做什么的？）

【中文对照——提交时请在英文填写稿中复制对应英文段落】

本应用是一个名为"波旁（美浦波旁）"的多功能 AI 陪伴型 Discord 机器人，基于 NoneBot2 和
Discord API 构建，由个人开发者运营，仅通过邀请加入少量社区服务器。其功能包括：

1. **带对话记忆的 AI 聊天**。用户通过输入"波旁 <内容>"或 @提及机器人与其对话。在服务器管理员
   开启的服务器/频道中，机器人还会参与自然的自由对话：它阅读频道内的自然对话流，缓冲连续几条
   消息，并通过一个 AI 判断步骤决定何时以自然的方式回复。它会保留每个频道/用户会话最近几轮对话，
   以保证回答连贯、有上下文意识。

2. **AI 图片生成**。如 "draw <提示词>"、`multidraw`、分辨率与工作流切换（"切换工作流"、
   "切换分辨率"）、负面提示词管理以及 Lora 管理（"lora列表"、"添加lora"、"删除lora"）等文本
   指令，全部以普通文本消息的形式输入聊天框。机器人从消息文本中解析指令词与参数，并在本地托管的
   ComfyUI 实例上渲染图片。

3. **知识学习**。"学习 <内容>" 以及管理员指令"批量学习"可让用户和管理员教给机器人知识；
   这些内容存储在本地知识库中，后续 AI 回答可以引用服务器专属的知识。

4. **内容审核**。在开启审核的频道中，机器人扫描每条消息是否存在垃圾/滥用内容，维护用户黑名单
   与按用户的绘图配额，并在具备所需 Discord 权限的情况下对反复违规者采取处理。哪些频道被监控由
   服务器管理员控制。

5. **日常与实用功能**。每日随机角色（"今日担当"）、图片搜索、定时消息、聊天内帮助指南
   （"help"），以及管理员指令，如删除消息（"撤回"）、封禁用户（"ban"）与重启机器人。

本机器人仅限邀请加入：它只在其运营者选择的服务器上运行，聊天与审核功能只处理各服务器管理员
已开启的频道。

## 三、Message Content Intent 部分

### 字段：Can users opt-out of having their message content data tracked?
（用户能否选择退出消息内容数据的追踪？）

```
No（不能）
```

说明（不需要填进表单，供你了解）：机器人没有逐用户"关闭记忆"命令；但机器人只加入运营者邀请的
服务器、只处理服务器管理员开启的频道，且不回复被拉黑用户的消息。如果以后想做得更好，可以给机器人
加一个"隐私模式/关闭记忆"的用户命令，能显著提高获批率与口碑。

### 字段：Are you storing message content data off-platform (outside of Discord)?
（你是否将消息内容数据存储在 Discord 平台之外？）

```
Yes（是）
```

说明（供参考）：会话历史、"学习"知识库和（管理员触发的）抓取存档保存在运营者自己的服务器/本机
数据库与 FAISS 文件中，不存到任何第三方平台；管理员可用"清除"命令整体清空会话库、用"删除知识"
删除知识条目。隐私政策中已如实说明。

### 字段：Will the message content data be used to train machine learning or AI Models?
（消息内容数据是否会被用于训练机器学习或 AI 模型？）

```
No（不会）
```

说明（供参考）：内容只被临时发送给生成回复/图片所需的 AI 与搜索 API（DeepSeek 对话、视觉理解、
联网搜索、本地 ComfyUI），运营者不用它训练任何模型。建议顺带在 DeepSeek 开放平台的数据设置中
关闭"使用数据训练"选项，以保持与声明的完全一致。

### 字段：Why do you need the Message Content intent?（你为什么需要 Message Content 权限？）

【中文对照——提交时请在英文填写稿中复制对应英文段落】

机器人的核心功能作用于它所在频道中消息的自由文本，而不是用户主动调用的斜杠命令：

1. **纯文本前缀指令**。几乎所有功能都由直接写在聊天框里的文本触发："波旁 <内容>" 用于 AI 对话，
   "draw <提示词>" / "multidraw" 用于图片生成，"高清" / "切换分辨率" / "切换工作流" /
   "lora列表" / "添加lora" 用于绘图选项，"今日担当" 用于每日功能，"学习 <内容>" 用于知识教学，
   "切换人设" 用于人格切换，"help" 用于命令指南。没有 Message Content 权限时，Discord 会剥离
   普通消息的内容，机器人将看不到指令词及其参数，以上功能全部无法运行。内置的消息内容豁免
   （提及机器人、回复与私信）在此没有帮助，因为用户是用文本前缀而不是 @提及机器人的方式来调用
   这些指令的。

2. **在已启用频道的自由对话**。机器人是一个 AI 聊天陪伴机器人。在由各服务器管理员开启的频道中，
   它跟随进行中的对话、缓冲几条消息，并通过一个 AI 判断步骤决定何时自然地回复。这需要读取既不是
   @提及机器人、也不是回复机器人的消息文本——这正是 Message Content 权限所提供的。

3. **在已配置频道的内容审核**。垃圾/滥用扫描、用户黑名单与反滥用配额必须在消息发送时检查每条
   消息的文本才能生效。

4. **对话记忆与知识支撑**。机器人会把最近几轮对话存储在本地，并使用服务器教给它的知识条目，
   使回答连贯且有依据；二者都建立在消息文本之上。

隐私保护措施：机器人仅限邀请加入，只处理其运营者选择的服务器；聊天与审核功能限定在各服务器管理员
开启的频道内；消息内容仅用于提供上述功能；内容绝不出售，也不会提供给第三方用于广告或用户画像，
仅在被临时发送给生成回复所需的 AI/视觉/搜索 API；运营者不使用这些数据训练任何机器学习模型。
会话历史存储在运营者自己的服务器上，管理员可用"清除"指令整体清空，知识条目可用"删除知识"移除，
用户也可联系运营者（见公开隐私政策）请求删除自己的数据。
