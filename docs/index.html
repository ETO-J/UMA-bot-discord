Bourbon (美浦波旁)
AI companion bot for Discord

A multi-function AI companion and community bot, built on an agent runtime with persistent conversation memory. Add it to a server you manage and talk to it like a companion — or let it keep an eye on moderation. The same Discord application also powers an optional web drawing interface.

What it does

💬 AI chat with memory

Talk with 波旁 <message> or by @mention. In enabled channels it follows the conversation, decides when to join in, and remembers recent context per channel.

📚 Teach it knowledge

Use /学习 to teach server-specific facts; answers can be grounded in that knowledge. Admins can manage entries with /知识列表 and /删除知识.

🖼️ Images & utilities

Send an image for understanding, use /识图 for source lookup, /涩图 for a random Pixiv image, or /今日担当 for a daily character.

🛡️ Moderation & admin

Optional trap-channel spam handling, message removal (/撤回, /长期撤回), /ban, and history archiving (/抓取). Only configured administrator IDs can use admin commands.

🎭 Personas & more

Switch its personality with /切换人设, get scheduled greetings, or use /帮助 for everything else.

🎨 Web drawing (optional)

Sign in to bourbon-draw.cn with Discord to use an AI image & video generation workspace. Drawing is a web feature — the bot itself does not run a drawing command.

Commands work with or without the leading / on Discord (e.g. 波旁 你好 = /波旁 你好). Administrator commands include /debug, /广播, /清除 and /重启.

Commands at a glance

/学习 <fact> · /批量学习* · /知识列表* · /删除知识*Teach and manage the knowledge base (*admin).

/识图 + image · /涩图 <keyword> · /今日担当Image utilities.
/撤回* · /长期撤回* · /ban* · /抓取*Discord moderation/admin (*admin).
/debug* · /广播* · /清除* · /重启*Operational commands (*admin).

Data & safety

The bot is invite-only and reads messages only in servers where its operator has installed it, and only in the enabled channels. Data is stored on the operator's own private server, never sold, and never used to train models. Conversation memory can be cleared with /清除. See the Privacy Policy and Terms of Service.
