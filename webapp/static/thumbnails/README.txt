LoRA thumbnail naming convention:
  {lora_filename}.png

Examples:
  my_character.safetensors -> my_character.safetensors.png
  pose_lora_v2.ckpt       -> pose_lora_v2.ckpt.png

Place PNG files here with the SAME NAME as the LoRA file + ".png" extension.
Recommended size: 256x256 or 512x512.
If no thumbnail exists, a placeholder will be shown.
